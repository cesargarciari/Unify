# Unify – Campus Event Management Platform

Unify is a group project developed for SENG 513 focused on improving how campus communities discover, manage, and engage with events.

Modern campuses face a major communication challenge: event information is scattered across multiple platforms, making it easy for students to miss opportunities. Unify solves this by centralizing campus events into one accessible system that connects organizers and students in a streamlined, user-friendly way.

## 🚩 Problem

Campus event communication is fragmented:

• Information is spread across social media, emails, posters, and websites

• Students miss events not due to lack of interest, but lack of visibility

• Organizers struggle to track attendance and engagement`

## 💡 Solution — Unify

Unify is a centralized event platform where:

• Organizers create and manage events

• Students discover events, RSVP, and receive reminders

• Administrators oversee platform activity

• Guests can browse public events

The goal is to simplify campus engagement and strengthen communication across the university community.

## ⭐ Core Features
#### 🔍 Event Discovery

Students can easily find events using:

• Search functionality

• Filters

• Category tags (clubs, sports, academic, social, etc.)

This removes the need to search across multiple sources.

### ✅ RSVP System

• Students reserve spots through a simple, mobile-friendly workflow

• Organizers track event capacity in real time

• Prevents overbooking and improves event planning

### 👥 Multi-Role Support

The system adapts based on user type:

• Students – Discover and RSVP to events

• Organizers – Create and manage events

## 🧰 Tech Stack

### Frontend

• Next.js – React framework for building the user interface

• Responsive, mobile-first design for event browsing and RSVP flows

### Backend

• FastAPI – High-performance Python framework used to build RESTful APIs

• Handles authentication, event management, RSVP logic, and role-based access

### Database

• PostgreSQL – Relational database for storing users, events, roles, and RSVP data
